Morpheus Compute (On-Chain Sessions)

Connect to the Morpheus Network decentralized compute marketplace on Base. Browse on-chain models, stake MOR tokens to open sessions with LLM providers, and chat through persistent per-session sockets.

How it works. The Morpheus Diamond Proxy at 0x6aBE…030a on Base hosts a registry of AI models and providers. You select a model, find a provider with good reputation, stake MOR to open a session, and get a persistent TCP connection to the provider's LLM endpoint for the session duration.

Brain Model Configuration

The Trinity Brain uses a local LLM for NER, significance scoring, semantic extraction, and reflection. It also uses an embedding model for vector search. You can run these via Ollama (default, easiest) or llama.cpp (lighter, faster cold start).

Ollama vs llama.cpp. Ollama manages model downloads and serves them behind a simple API — recommended if you want things to just work. llama.cpp loads a single GGUF file directly, uses less RAM with quantized models (Q4_K_M), and starts instantly — better for resource-constrained hosts. Both expose a compatible API; you can switch at any time.

Brain Backup

Automatically back up the trinity-brain container's data (memories, vectors, knowledge graph, skills) to an external destination. Backups are tar.gz archives.

Local / Mounted Drive

Amazon S3 / S3-Compatible

Backblaze B2

B2 uploads use the AWS CLI with S3-compatible mode. Ensure aws is installed on the host.

FTP / SFTP

Google Drive (via rclone)

Google Drive backups use rclone. Run rclone config on the host to create a remote named trinity-backup, then select Google Drive as the backend.

Azure Blob Storage (via rclone)

Azure backups use rclone. Run rclone config on the host to create a remote named trinity-backup, then select Azure Blob as the backend.

Restic Repository

Requires restic installed on the host. rclone is used as the transfer backend.
