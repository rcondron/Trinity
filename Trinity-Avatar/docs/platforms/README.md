# Platform guides

All platforms are selected with `?platform=<id>` (or the ◫ panel in the app).
Every hardware platform has an in-browser simulator so it's demonstrable
without owning the device.

| Guide | Platform |
|---|---|
| [webxr.md](webxr.md) | VR headsets & AR (phones, passthrough, Vision Pro via Safari) |
| [looking-glass.md](looking-glass.md) | Looking Glass light-field displays |
| [volumetric.md](volumetric.md) | Spinning-arm / POV / voxel displays (experimental) |
| [peppers-ghost.md](peppers-ghost.md) | Hologram pyramids & fans |
| [desktop-overlay.md](desktop-overlay.md) | The avatar walking on your desktop |
| [mobile.md](mobile.md) | Native iOS/Android via Capacitor |
