Welcome to Trinity

Trinity is a decentralized AI agent for the Morpheus Network. Choose where you'd like to go:

Onboarding Wizard →

First-time setup: install Docker, spin up containers, configure the agent, create your wallet.

Dashboard →

Command & control center. Monitor containers, gateway, brain, and Morpheus sessions.

Chat with Trinity →

Talk to the agent through the Bridge. Messages route via WebSocket RPC to the gateway.

Settings →

API keys, model config, brain backup, Morpheus compute, wallet management.

Skills →

Browse and teach Trinity skills. Stored in the Brain, evolved through use.

Test Suite →

Run unit, e2e, gateway, and extension tests. View results in the browser.
