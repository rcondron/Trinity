Skills

Trinity's skills live in the trinity-brain container, not on disk. The agent grows its skill library as it learns — every successful use nudges a skill's significance up, every failure nudges it down, and new skills can be evolved from old ones.

No bundled skills folder. There is no skills/ directory on the host. The brain is the single source of truth so the agent's knowledge can update itself without the webapp or host filesystem getting in the way.
