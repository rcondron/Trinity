How to run from the terminal

# From the project root:
cd Trinity-Agent

# Run a specific suite:
pnpm vitest run --config ../Trinity-Tests/vitest.unit.config.ts

# Run all tests:
pnpm vitest run --config ../Trinity-Tests/vitest.config.ts

# Watch mode:
pnpm vitest --config ../Trinity-Tests/vitest.unit.config.ts
